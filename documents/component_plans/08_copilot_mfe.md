# Implementation Plan: AI Merchandising Copilot Micro Frontend (React 18)

## 1. Overview
The AI Merchandising Copilot MFE provides vendors with a side-by-side review interface. Vendors can compare raw product details against AI-generated SEO titles, marketing descriptions, feature bullet points, and auto-generated tags generated by the containerized SLM before approving or tweaking them for publication.

---

---

## 3. Implementation Steps

### Step 1: Side-by-Side Review Component
* Left Panel: Vendor's raw submitted details (Title, Raw Description, Basic Specs).
* Right Panel: SLM enriched output (`seoTitle`, `marketingDescription`, `bulletPoints`, `generatedTags`).

### Step 2: Approval & Publishing Workflow
```tsx
const handleApprove = async () => {
  await api.post(`/api/catalog/products/${productId}/approve`, {
    finalTitle,
    finalDescription,
    finalTags,
  });
  navigate('/vendor/products');
};
```
